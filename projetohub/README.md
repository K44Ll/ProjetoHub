# Aplicação ProjetoHub

Este diretório contém a aplicação Next.js do ProjetoHub.

A documentação completa, incluindo funcionalidades, hierarquia, configuração do Supabase, segurança e deploy, está no [README principal](../README.md).

## Desenvolvimento

```bash
npm install
npm run dev
```

A aplicação estará disponível em [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run lint
npm run build
```
